## 1. Constraints & Philosophy

* **Zero Sudo Access**: The user `akash` does not have root/sudo privileges. All tools (JDK 21, Maven, Python venv, databases) will be installed cleanly inside the user's home directory (`~/tools` and `~/.local`).
* **100% Free & Zero Cloud**:
  * **No paid cloud servers** (AWS/GCP/Azure) — everything runs locally on `rbkasus`.
  * **No paid cloud databases** — local DuckDB (Parquet analytics) + embedded H2/PostgreSQL engine.
  * **No paid AI API subscriptions** — local open-source LightGBM / XGBoost / ONNX on your Intel CPU.
* **Low Footprint**: Keeps RAM usage $< 500\text{ MB}$, leaving all resources free for your 24/7 Minecraft server and Jellyfin media server.

### Step 2: User-Level Java 21 JDK Setup (Eclipse Temurin)

Since `/usr/lib/jvm` only contains headless runtime without `javac`, we download the official Eclipse Temurin JDK 21 binary tarball directly into `~/tools/jdk-21` (zero sudo needed):

```bash
# 1. Create tools directory in user home
mkdir -p ~/tools

# 2. Download and extract Eclipse Temurin OpenJDK 21
curl -sL https://github.com/adoptium/temurin21-binaries/releases/download/jdk-21.0.4%2B7/OpenJDK21U-jdk_x64_linux_hotspot_21.0.4_7.tar.gz | tar -xz -C ~/tools/

# 3. Create a clean symlink for easy path reference
ln -sfn ~/tools/jdk-21.0.4+7 ~/tools/jdk-21

# 4. Verify compiler
~/tools/jdk-21/bin/javac -version
~/tools/jdk-21/bin/java -version
```

### Step 3: User-Level Apache Maven Setup

Download standalone Apache Maven 3.9.x binary into `~/tools/maven` (zero sudo needed):

```bash
# 1. Download and extract Apache Maven
curl -sL https://archive.apache.org/dist/maven/maven-3/3.9.8/binaries/apache-maven-3.9.8-bin.tar.gz | tar -xz -C ~/tools/

# 2. Create clean symlink
ln -sfn ~/tools/apache-maven-3.9.8 ~/tools/maven

JAVA_HOME=~/tools/jdk-21 ~/tools/maven/bin/mvn -version
```

### Step 5: Zero-Cost Local Database & Columnar Storage Setup

We create a structured local data hierarchy on disk:

```bash
# Create local data directories
mkdir -p data/raw          # Daily 40-byte binary .raw WAL envelopes
mkdir -p data/parquet      # Daily partitioned ZSTD Parquet files
mkdir -p data/db           # Local embedded metadata database files
mkdir -p data/models       # Exported model.onnx artifacts and JSON metadata
```

#### 🗄️ Database Architecture (100% Local & Free):
1. **For Parquet Analytics (Python / Research)**: **DuckDB**
   * Operates directly on disk Parquet files (`data/parquet/**/*.parquet`).
   * Uses vectorized SIMD CPU execution.
   * Zero memory bloat, zero background process, zero cost.
2. **For Metadata & Session Tracking (Java Spring Boot)**: **H2 in PostgreSQL-Compatibility Mode**
   * Connection URL: `jdbc:h2:file:./data/db/orderbook_meta;MODE=PostgreSQL;DATABASE_TO_LOWER=TRUE;AUTO_SERVER=TRUE`
   * Provides full ANSI SQL, ACID transactions, and Spring Data JPA support.
   * Embedded inside the JVM — starts and stops automatically with Java.
   * Zero background daemon eating RAM while you sleep!
